### Reviewer focus

- PROVENANCE GOES THROUGH VERBATIM. The server binds the pinned set and REFUSES an incomplete one; a client that filters provenance.activeBatchIds to 'the relevant ones' converts a refusal into a silently wrong footer. Check the array reaches the request untouched - not filtered by source, not deduped, not trimmed to the block's months.
- BUILD THE REQUEST FROM THE RESPONSE, NOT THE SELECTORS. The export control already does this for a reason: a reader who changes a dropdown after generating must still drill the statement they are looking at. Read scope off the resolved response.
- DO NOT RE-SORT ON THE CLIENT. The server's order is deterministic by contract (Value desc, Month desc, posting_date desc, txn_no, line_id) and pagination depends on it. Any client-side sort silently breaks page boundaries.
- THE FOOTER IS THE SERVER'S FULL-RESULT TOTAL. Summing the rows on screen gives a PAGE subtotal that will match on a single-page leaf and quietly lie on a paged one - which is exactly the case the client extract cannot produce, so a test must fabricate it.
- ONE STATE AT A TIME. Replaced, stale, forbidden, failed and empty are five distinct outcomes; none may render beside rows, and none may render beside another. mis-report-view shipped an error and an empty-state together once - constitution 07 exists because of that class.
- LEAF ACTUALS IN BOTH PLACES. Task 2 deliberately left them inert in the statement AND in the panel's leaf rows, and held the guidance copy. Both are this task's to activate; a task that wires only the statement leaves the panel's own rows as the false affordance we avoided.
- TASK 2'S AGGREGATE PATH MUST STAY OFFLINE. Decision 0024: opening a non-leaf still issues zero requests. The existing spy test must keep passing untouched - if it needed changing, something regressed.
- CHECK THE EXECUTED COUNT AND TESTCASE NAME in every artifact, never the exit code (D-0031).
- THE API-CLIENT LEAF IS NOT A COMPONENT TEST. Component tests mock the client, so they cannot prove the route path, the CSRF header, the retry-on-401 or that pinnedBatches reached the wire untouched. frontend/src/lib/api.test.ts:52 is the pattern; the required leaf must live there.
- batchStatuses IS A LIST. An FY-YTD drill can carry several replaced batches. A find() renders one and hides the rest; the criterion requires every replaced source and period to be named.
- PENDING IS A STATE WITH RULES: navigation disabled, the previous page still visible with a loading indication, and a terminal failure CLEARS rows, count and footer. Stale numbers beside an error is the constitution-07 defect this codebase has shipped before.
- DATE-ONLY STRINGS, UTC-SAFE. month and postingDate arrive as date-only strings; a local-time Date shifts them a day east of UTC, and rendering them raw repeats the ISO-label defect fixed in task 2. statement-view already parses at UTC midnight - follow it.
- THE SEVEN-COLUMN TABLE NEEDS ITS OWN STYLING. .mis-drill-table's positional rules (nth-child(3), nth-child(n+4)) encode the SIX-column aggregate layout and will misalign these columns.
- FOCUS MUST NEVER LAND ON AN UNMOUNTED CONTROL. Drilling a leaf from inside the panel swaps the body in place; Back returns to the group with focus on the leaf row used; Close returns to the statement button, which stays mounted throughout.
