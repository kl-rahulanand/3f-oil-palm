- Navigation must happen BEFORE the await. An `if (await ...) push()` anywhere in the Open handlers is the defect this task exists to remove.

- Matching and the failure policy are task 1's. Any new selection comparison or refusal branching here is duplicated logic that will drift.
- scrollIntoView must be asserted, not assumed - jsdom does not implement it, so an unmocked call silently does nothing and a test can pass without it.
- The busy path must NOT navigate; check a leaf covers it, since navigate-first makes it easy to navigate unconditionally.
- Task 1's fifteen leaves must pass unmodified.
