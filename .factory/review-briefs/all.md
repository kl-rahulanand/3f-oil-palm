- The secret must have NO development fallback, but the requirement belongs where the provider is CONSTRUCTED - putting it in loadConfig() breaks every existing hermetic leaf.
- The node-metadata digest must be inside the signed material. If only the outline is signed, the readable metadata is forgeable and a later aggregate explanation would present a false mapping as attested.
- Membership must be checked against a RE-READ outline whose digest matches the claim. A digest alone cannot answer membership.
- Every refusal must be TYPED and distinguishable. A generic 400, or a mismatch answered as 'No mapping configured', is the defect this task removes.
- A verified grounded request must not fall into the LLM path - task 2 owns the answer, and silently reaching the model here would ship an unreviewed behaviour.
- New test files must appear in BOTH backend/package.json and tools/quality-gate.test.mjs, or the gate fails or the leaf never runs.
- The shipped statement and export leaves must pass unmodified - both new fields are additive and optional in the type.
