### Reviewer focus

- EVERY NUMERAL MUST COME FROM THE RESPONSE. The entire trust story is that the model never produces a figure. A client that formats, derives, sums or interpolates a number - even a row count phrased in prose - breaks it. Check the rendered output against the payload, not against the component's intent.
- THE VERIFIED BADGE IS NOT DECORATION. It renders only when provenance.verified is true. A badge driven by 'we got a 200' certifies answers nobody checked, which is worse than no badge.
- THE SEVEN CLASSES DO NOT SHARE ONE SHAPE. Informational carries title/definition/suggestedQuestions, NOT message - a renderer keyed on message alone yields a blank informational answer. Clarification carries prompt and options. Only the four failure classes carry message. One state at a time, always.
- viewInReport IS A UNION AND BOTH ARMS ARE VISIBLE. available: false must SHOW its reason. And the client must never rebuild a selection from the answer - it links with what the server gave it.
- THE STALE-LINK PROOF BELONGS IN mis-report-view.test.tsx. api.ts types runMisStatement as MisStatementRunResponse, not the route union task 1 added, so a refresh-required response reaches StatementView missing fields it reads. An ask-panel test cannot prove the statement route parsed the selectors, posted them and rendered the refusal.
- PRIOR TURNS ARE SUCCESSFUL TURNS ONLY. AskPriorTurn requires a selection and only a success supplies one; a hook that invents a selection for a clarification or an error turn sends the model something the user never got. The api leaf must assert the EXACT body, not just the absence of conversationId.
- SEEDED CHIPS MUST BE ANSWERABLE. The human chose 3F-specific prompts; that only works if they are drawn from the registered catalog (governed-financial, mis-statement, the DUB slice). A chip that returns unsupported reads as the product being broken, which is the exact risk of this choice.
- RECHARTS IS A NEW DEPENDENCY (decision 0007). It is absent from frontend/package.json, so the lockfile moves too. A chart the client cannot draw honestly must fall back to the table - never to a chart that misrepresents the shape.
- DESIGN PARITY IS AGAINST docs/design/3F-Financial-MIS, and 'Ask' must become a live shell destination - it is disabled at app-shell.tsx:15 today. Check the EXECUTED COUNT and testcase name in every artifact, never the exit code (D-0031).
