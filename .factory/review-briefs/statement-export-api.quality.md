### Reviewer focus

- EXPORT DRIFT, per request: the route calls MisStatementService.run ONCE and the writer receives that resolved payload. A writer that re-queries or re-derives anything is free to disagree with the screen.
- The JSON/XLSX boundary must branch BEFORE any header is set. An unresolvable request returns ordinary JSON with no file headers - otherwise a blob client saves a JSON body as .xlsx and hands Srihari a corrupt download.
- FORMULA INJECTION: the sheet's text comes from a client-supplied workbook and the export is sent to other people. A cell beginning =, +, - or @ must not reopen as a formula. This is the security lens's main object here.
- Amounts are numbers ROUNDED TO THE RUPEE - the human's ruling - so the sheet matches the screen line for line. Not raw paise, and not pre-formatted strings: a recipient who cannot sum a column has a picture of a statement.
- Content-Disposition must be in the CORS exposedHeaders in main.ts, or the browser cannot read the filename in the next task and the download lands with a generated name.
- Name the real protections: AuthGuard plus RequireAction('report') under the global CSRF guard. SessionGuard is the FRONTEND guard and does not exist on this route.
- The gated test registration must appear EXACTLY once in backend/package.json and once in tools/quality-gate.test.mjs, which verifies those lists exactly.
- This is the FIRST download route: streaming, filename and headers set the pattern drill-down's transactions sheet will follow. constitution/pnp-coding-standards-modular-monolith.md governs the service's own .interface.ts, and it consumes the statement service rather than reaching past it.
