# Symphony Forge Project Memory

Durable project facts live here so every clone and runtime sees the same
context. Keep each fact in a focused file with Claude-compatible memory
frontmatter. Decisions and the constitution remain authoritative when a memory
note drifts.

## Workflow

- [Factory entry contract](factory-entry-contract.md) — specs, roadmap,
  sign-off, and the two legitimate exits from the planning lock.
- [Signal resolution is auto](signal-resolution-is-auto.md) —
  permission-shaped worker signals are resolved autonomously via the
  ledgered paths; humans gate plans, decisions, and scope changes only.
- [Decisions during planning stale the requirements grill](decisions-during-planning-stale-the-requirements-grill.md)
  — mint and accept a story's decisions BEFORE recording its requirements pass, or pay for
  a second cold read and a second human round at `plan save`.
